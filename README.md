## 1. Verification Method

| Step | What Happens |
|---|---|
| Test | Code entered at the store's checkout; discount confirmed |
| Date | Test date shown beside the code |
| Re-label | After 45 days without a re-test, label changes to "last checked" |
| Retire | Failed or ended codes move to an expired list and stay on the page, marked expired |

## 2. Code Status Labels

| Label | Meaning |
|---|---|
| Verified + date | Tested at checkout on the date shown |
| Last checked | Not re-tested in the last 45 days |
| Expired | Failed or past its end date |

## 4. Pre-Checkout Checklist

| Check | Why |
|---|---|
| Test date | Confirms freshness |
| Status label | Flags older or expired codes |
| First-order / minimum spend | Avoids failed codes |
| Sign-up requirement | Some offers need an account or text sign-up |
| Shipping time | Plans delivery (Amino Tech: 2–3 business days after payment) |
| Return policy | Some stores are final sale (Amino Tech: all sales final) |
| Research-use terms | Products are for laboratory research only |

## 6. FAQ

**Where can dated peptide coupon codes be found?**
On Peptide Coupons, where each verified code shows its checkout test date.

**What does "last checked" mean?**
The code has not been re-tested in 45 days.

**Are the products for human use?**
No. The site states products from listed stores are for laboratory research use only, not for human or veterinary use.
